# Проверка изменений

## PHP

Минимальные проверки для `main`:

```bash
find 'Сайт' 'Форум' -type f -name '*.php' -print0 | xargs -0 -n1 php -l
php tests/site-core.php
php tests/forum-core.php
bash tools/http-smoke.sh
```

Первые две группы проверяют синтаксис и инварианты авторизации/прав доступа; HTTP smoke-тест поднимает **только localhost** PHP-сервер и проверяет, что пути `app/`, `storage/` и `.htaccess` закрыты, а установщик и статические файлы доступны.

Не заменяет тесты на реальном Apache/Nginx: локальный `tools/dev-router.php` эмулирует только минимальные запреты.

## Игра (ветка develop/gameplay-mvp)

Workflow `.github/workflows/game.yml` загружает официальный Pawn-компилятор, компилирует `Игра/gamemodes/veltor.pwn`, запускает open.mp с bcrypt-плагином в изолированном CI и проверяет сообщение об инициализации SQLite. На GitHub Actions доступен временный `veltor-gamemode-amx` артефакт.

Эти проверки **не подтверждают** корректность игрового процесса, регистрацию через реальный клиент, работу транспорта, экономику при нескольких игроках и готовность к публичному размещению.

## Минимальная ручная приёмка

- Установка обоих веб-приложений на чистые отдельные хранилища.
- Вход/выход; смена пароля; отказ доступа неавторизованным.
- Создание и редактирование новости; сохранение заявки магазина.
- Форум: создание темы, приватная жалоба, ответы, модерация; другой игрок не может прочитать чужую жалобу.
- Резервное копирование и восстановление хранилищ.
- Для игры: два настоящих клиента, повторный вход, сохранение денег/транспорта, проверка команд и отказов авторизации.

Если тест не проведён, не отмечайте его как успешный.
