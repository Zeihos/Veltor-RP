# Установочные архивы VELTOR ROLEPLAY

Исходный код сайта и форума хранится в репозитории. Для удобства развёртывания GitHub Actions автоматически создаёт **чистые ZIP-архивы**.

## Где получить файлы

1. Откройте [GitHub Actions — Веб-сборки](https://github.com/Zeihos/Veltor-RP/actions/workflows/web-packages.yml).
2. Выберите последнюю **успешную** сборку ветки **main**.
3. Внизу страницы скачайте **VELTOR-WEB-INSTALLERS**. Для загрузки артефактов GitHub может потребоваться авторизация.
4. Внутри будут:
   - **VELTOR-SITE.zip** — содержимое корня сайта, готовое к загрузке в документ-корень PHP-хостинга;
   - **VELTOR-FORUM.zip** — содержимое корня форума, для отдельного виртуального хоста;
   - **SHA256SUMS.txt** — контрольные суммы ZIP, чтобы проверить целостность.
5. Разархивируйте файлы в **разные** корни, настройте HTTPS и ограничения доступа, затем откройте соответствующие \`install.php\`.

**Важно:** это установочные пакеты исходников веб-приложений, не релиз игрового сервера. Их автоматическое создание и успешные тесты не гарантируют готовность к любому публичному хостингу.

Артефакты доступны ограниченный срок (настроено **30 дней**). При необходимости запустите workflow повторно через **Run workflow**. В этом репозитории не опубликованы постоянно поддерживаемые релизы или платёжные интеграции.

## Что попадает в архив

Только файлы запуска каждого приложения: \`index.php\`, \`install.php\`, \`.htaccess\`, файлы \`app/\`, \`assets/\`, и защитные \`storage/.htaccess\` и \`storage/index.php\`.

В установочный пакет **не включаются** файлы Git, тесты, документация разработчиков, пользовательские базы, резервные копии, дампы SQL, логи и временные файлы. Каждое содержимое ZIP проверяется байт-в-байт по исходникам перед публикацией.

## Важно для публичного сайта

\`app/\` и \`storage/\` **не должны открываться через HTTP**. На Apache должны работать \`.htaccess\`, на Nginx их ограничения настраиваются отдельно — см. [DEPLOYMENT.md](./DEPLOYMENT.md). У сайта и форума отдельные системы аккаунтов.
