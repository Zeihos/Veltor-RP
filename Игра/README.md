# Игра — VELTOR ROLEPLAY (экспериментальный сервер)

Это **отдельный тестовый мод Pawn/open.mp**, а не восстановленная оригинальная сборка RADMIR RP. В этой папке нет игровых аккаунтов, SQL-дампов, секретов или исполняемых файлов. Код вынесен в отдельную ветку для проверки до слияния с `main`.

**Текущие функции:** вход/регистрация через диалог, SQLite-аккаунты, стартовая позиция, 3 работы, игровая валюта, покупка личного автомобиля и RP-команды `/me`, `/do`, `/b`. Команда `/report` теперь сохраняет обращение в SQLite, а не только выводит его в консоль.

## Локальный запуск на Windows

1. Установите клиент SA-MP/open.mp с легальной GTA San Andreas.
2. Запустите `START.bat` из этой папки (первый запуск требует интернет).
3. Скрипт скачивает открытые официальные релизы сервера open.mp `v1.6.7.3218` и компилятора `v3.10.11`, собирает `veltor.pwn`, затем запускает сервер.
4. Подключитесь к `127.0.0.1:7777`. Если сборка не удалась, сохраните `BUILD-LOG.txt` и отправьте его для диагностики.

## Ограничения и риски

- Это **dev build**. Компиляция Pawn уже проверяется в GitHub Actions. Реальные игровые сценарии с двумя клиентами и публичная безопасность ещё не подтверждены.
- Регистрация и вход теперь используют **асинхронный bcrypt** через плагин `Sreyas-Sreelal/samp-bcrypt` (закреплённая версия 0.4.1, cost 12). Плагин скачивается Windows-установщиком из релиза разработчика; исходники стороннего компонента не входят в проект. Старые тестовые аккаунты SHA-256 **не поддерживаются**: необходим сброс пароля или новая чистая локальная база. Не импортируйте чужие данные.
- Задержка `/work` теперь сохраняется в отдельной SQLite-таблице и не сбрасывается при переподключении; строгая проверка аргументов `/pay` добавлена. Проверки экономической устойчивости в реальном мультиплеере ещё нужны.
- Учётные записи **не связаны** с сайтом и форумом. Нельзя импортировать старые пользовательские дампы из неизвестных источников.
- Исполняемые файлы и база `server/scriptfiles/veltor.db` должны оставаться локальными и не коммититься в Git.

Следующие этапы — проверить запуск с bcrypt-плагином, регистрацию и вход на двух игровых клиентах, восстановление после падения сервера, отдельную систему модерации и интеграцию с порталом. **Локальный тестовый сервер по умолчанию слушает только 127.0.0.1**; открывать его в интернет без дополнительного аудита нельзя.

### Учётные данные

Созданные локально аккаунты сохраняются в `server/scriptfiles/veltor.db`. Удаление базы сбрасывает всех тестовых игроков. До любых миграций сначала делайте резервную копию. Не добавляйте файл базы в Git.

## Модерация — тестовая версия

Права сотрудников **не выдаются через игровой чат**. Владелец запускает локальную утилиту на **остановленном сервере**, после регистрации нужного аккаунта:

```bash
python Игра/tools/staff_admin.py grant Test_Player
python Игра/tools/staff_admin.py revoke Test_Player
```

По умолчанию утилита обращается к `Игра/server/scriptfiles/veltor.db`, альтернативный путь задаётся `--db ПУТЬ`. Изменение прав применяется при **следующем входе** игрока. Ник проверяется, а запросы к SQLite параметризованы. Права нельзя получить с помощью `/setadmin` и не следует редактировать файлы незнакомых серверов.

**Команды для всех игроков:** `/report описание` — обращение длиной не менее 10 символов (не чаще одного раза в 60 секунд).

**Команды сотрудников:** `/ahelp`, `/reports` (последние пять открытых обращений), `/rclose ID`, `/kick ID`, `/mute ID минуты` (1–1440 минут), `/unmute ID`.

Открытые обращения, закрытия, временные блокировки чата и журнал действий сотрудников записываются в локальную SQLite. Блокировки чата переживают переподключение. Сообщения чата ограничены интервалом в две секунды. Сотрудники не могут применить `/kick` или `/mute` к другим сотрудникам.

**Ограничения:** закрытие жалобы пока не уведомляет игрока, жалобы видны в игре только сотрудникам, нет веб-панели модерации, полноценной системы наказаний и автоматической проверки действий модератора. До публичного использования нужны проверка прав на настоящем сервере, резервное копирование и тестирование различных сценариев.
