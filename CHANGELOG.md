# Журнал изменений

Все изменения фиксируются в истории Git и Pull Requests. Ниже — вехи работ, **не** обещание выпущенной публичной версии.

## 2026-11-17 — упорядочивание репозитория

- Русскоязычный README и документация по архитектуре, установке, тестированию и плану развития.
