# Безопасность VELTOR ROLEPLAY

## Сообщения об уязвимостях

Не публикуйте в публичных issue пароли, токены, личные данные игроков или инструкции эксплуатации живого сервера. Если для репозитория доступна функция GitHub **Security → Report a vulnerability**, используйте её. Иначе свяжитесь с владельцем проекта конфиденциальным способом до публикации деталей.

Укажите затронутый компонент (`Сайт`, `Форум`, `Игра`), версию/коммит, условия воспроизведения и предполагаемый риск. Не тестируйте сторонние серверы без разрешения.

## Обязательные меры при развёртывании

- **Не публикуйте** папки `app/` и `storage/` по HTTP.
- Для Apache требуются работающие `.htaccess`; для Nginx — отдельные правила из `deploy/`.
- Запускать на HTTPS, хранить резервные копии вне веб-корня и ограничивать доступ к ним.
- Не коммитить базы игроков, логи с персональными данными, реальные пароли, токены, выгрузки третьих лиц.
- Игровую ветку нельзя считать публично защищённой без тестов аутентификации, нагрузки и модерации.
- У сайта, форума и мода **разные** аккаунты; не переносите пароли между ними.

`tools/dev-router.php` — **локальный инструмент**, не замена правилам производственного веб-сервера.
