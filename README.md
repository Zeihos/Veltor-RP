## О проекте

**VELTOR ROLEPLAY** — самостоятельная разработка ролевого мультиплеерного проекта. Здесь собраны исходники веб-портала, форума, оформление сообществ и экспериментальный игровой мод.

Мы развиваем проект поэтапно: сначала надёжная техническая основа, затем игровые системы, интеграции, тестирование и публичный запуск.

> [!IMPORTANT]
> **Сейчас проект находится в разработке.** Сайт и форум доступны в виде исходного кода для самостоятельного развёртывания. Игровой мод компилируется и запускается в автоматическом тесте, но **не прошёл полноценное тестирование с реальными игроками**. Адрес публичного сервера и дата открытия пока не объявлены.

| Направление | Что уже есть | Что предстоит |

| **Сайт** | Страницы, аккаунты, панель управления | Проверка на боевом хостинге, интеграция с игрой |
| **Форум** | Разделы, темы, жалобы, модерация | Антиспам, нагрузочные и эксплуатационные тесты |
| **Игровой сервер** | Исходник, SQLite, bcrypt, базовые RP-команды | Тестирование нескольких игроков, игровые системы |
| **Общая инфраструктура** | GitHub Actions, тесты, документация | Единая авторизация, резервное копирование, мониторинг |

> **Важно:** сборка игры в GitHub Actions — это не подтверждение готовности игрового сервера к публичному запуску. Сайт, форум и игра пока используют **разные учётные записи**. Магазин сайта принимает заявки, но **не проводит платежи**.

## Быстрый старт

### Сайт и форум

Для обоих приложений нужен **PHP 8.1+**; MySQL не требуется. Каждое приложение хранит данные отдельно.

```bash
# Сайт — локально, только для разработки
php -S 127.0.0.1:8000 -t 'Сайт' tools/dev-router.php

# Форум — во втором терминале
php -S 127.0.0.1:8001 -t 'Форум' tools/dev-router.php
```

Затем откройте `http://127.0.0.1:8000/install.php` и `http://127.0.0.1:8001/install.php`. Для настоящего хостинга требуются HTTPS, защита каталогов `app/` и `storage/`, резервное копирование и отдельные корни для сайта и форума.

**[Полное руководство по развёртыванию →](./docs/DEPLOYMENT.md)**

### Игровой сервер

Игровой код **не входит в `main`**. Он находится в ветке [`develop/gameplay-mvp`](https://github.com/Zeihos/Veltor-RP/tree/develop/gameplay-mvp). Инструкция локального запуска — в [`Игра/README.md`](https://github.com/Zeihos/Veltor-RP/blob/develop/gameplay-mvp/%D0%98%D0%B3%D1%80%D0%B0/README.md).

Не используйте экспериментальный сервер для публичной регистрации без дополнительной проверки.
