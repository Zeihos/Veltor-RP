# Как вносить изменения

1. Выберите компонент: `Сайт/`, `Форум/`, `Оформление/` или игровая ветка `develop/gameplay-mvp`.
2. Создайте отдельную ветку. Для изменений игры используйте Pull Request в черновом состоянии, пока не пройдены автоматические и игровые тесты.
3. Не удаляйте файлы оформления только потому, что они дублируются в сайте и форуме: компоненты размещаются отдельно.
4. Не коммитьте `storage/`, скомпилированные `.amx`, исполняемые файлы, архивы из интернета, креденшелы и сторонние выгрузки пользователей.
5. Пройдите `php -l`, `tests/*.php` и `tools/http-smoke.sh` для изменений PHP. Для игры дождитесь проверки Pawn в GitHub Actions.
6. В Pull Request напишите что изменено, как проверено и какие ограничения остались.

Исходники и материалы сторонних проектов добавляйте только при наличии права на распространение. Не подменяйте сообщение об успешной компиляции утверждением, что весь продукт готов к публичному релизу.

См. [архитектуру](./docs/ARCHITECTURE.md) и [план](./docs/ROADMAP.md).
