# Участие в разработке VELTOR ROLEPLAY

Спасибо за интерес к проекту! Основной язык общения — **русский**.

## Обратная связь

- [Сообщить об ошибке](https://github.com/Zeihos/Veltor-RP/issues/new?template=bug_report.yml) — если нашли конкретную проблему.
- [Предложить улучшение](https://github.com/Zeihos/Veltor-RP/issues/new?template=feature_request.yml) — если есть полезная идея.
- [Текущие задачи](./docs/ROADMAP.md) — перед созданием нового предложения.

Для уязвимостей безопасности **не открывайте публичный issue**: см. [SECURITY.md](./SECURITY.md).

## Работа с кодом

1. Определите компонент: `Сайт/`, `Форум/` или `develop/gameplay-mvp/Игра`.
2. Создайте отдельную ветку и внесите только связанные изменения.
3. Не удаляйте изображения из приложений как «дубликаты»: сайт и форум развёртываются независимо.
4. Запустите подходящие проверки и укажите результат в Pull Request.
5. В описании Pull Request объясните **что изменилось**, **зачем**, **как проверяли** и **что ещё не готово**.

### Проверки сайта и форума

```bash
find 'Сайт' 'Форум' -type f -name '*.php' -print0 | xargs -0 -n1 php -l
php tests/site-core.php
php tests/forum-core.php
bash tools/http-smoke.sh
```

### Игровая разработка

Игровой мод пока находится в отдельной ветке `develop/gameplay-mvp`. Проверка CI компилирует Pawn и запускает тестовый open.mp, но **не заменяет тест с реальными игровыми клиентами**. Не объединяйте черновой Pull Request с `main`, пока не закрыты ошибки и риски безопасности.

## Что нельзя публиковать

Не загружайте в Git реальные пароли, токены, пользовательские базы, логи с личными данными, скомпилированные бинарники, чужие закрытые исходники, нелицензированные активы и архивы из сомнительных источников.

> Публичная доступность репозитория сама по себе не означает разрешение на свободное копирование или перераспространение его содержимого. До добавления отдельной лицензии права на материалы остаются у соответствующих правообладателей.
